# Mother Losing Soul

An interactive web project exploring themes of spirituality, faith, and the soul in our modern world.

## Project Overview

This project is a reflective exploration inspired by religious concepts and concerns about the future. It presents a multimedia experience that examines how our rapidly advancing world may be losing its spiritual essence.

## Core Concept

The project centers on the question: "Where is our world heading? What will it become? Does the future lack soul?" Through visual storytelling, the work presents the metaphor of a cracked mother figure whose soul slowly disappears, symbolizing the loss of spiritual depth in our technological age.

## Project Structure

- **index.html** - Main HTML structure and layout
- **styles.css** - Styling and visual design
- **script.js** - Main interactive functionality
- **mouseController.ts** - Mouse event handling and interaction system
- **future-traces/** - Additional assets and resources

## Features

- Background video element for immersive experience
- Interactive mouse controller for dynamic user engagement
- Multi-section layout with:
  - Introduction section ("Mother Losing Soul")
  - Concept & Inspiration
  - Research & Exploration
- Image galleries for visual documentation
- Responsive design with custom typography

## Technical Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling and layout
- **TypeScript** - Type-safe interactive functionality
- **JavaScript** - Client-side interactivity

## How to Use

1. Open `index.html` in a web browser
2. Interact with the page using your mouse to trigger events
3. Explore the different sections and view the gallery images

## Installation

No installation required. Simply open the `index.html` file in any modern web browser.

## Browser Requirements

- Modern browser with HTML5 video support
- JavaScript enabled
- ES6+ support (for TypeScript compilation)
